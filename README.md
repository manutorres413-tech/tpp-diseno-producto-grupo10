# Proyecto AURA • Diseño de Producto 2026 (Grupo 10)
### Cátedra: Diseño de Producto — UTN Buenos Aires

Desarrollo estratégico y diseño industrial de una solución integral de protección para procesadores externos de implantes cocleares y audífonos retroauriculares frente a sudor, lluvia, arena, polvo y caídas.
